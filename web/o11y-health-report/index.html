Open a health check report

Drop your consolidated markdown here, or choose a file. By default the script writes under reports/; this page auto-loads report.md in this folder (the bundled file is a demo sample). Use --out web/o11y-health-report/report.md when generating, or use a ?report= URL (see hint below — paths must be reachable from the same HTTP origin).

Viewer-only server (serves this folder): python3 -m http.server 8765 --directory web/o11y-health-report — use bundled report.md, --out web/o11y-health-report/report.md, or Choose file. To load from reports/<file>.md via URL, run the server from the repo root: python3 -m http.server 8765 and open http://localhost:8765/web/o11y-health-report/?report=/reports/Your%20Report.md. Health Check Hub (o11y_health_hub_server.py) opens reports with ?report=/api/jobs/…/markdown automatically.
